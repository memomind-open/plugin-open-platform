# Known Limitations

- This is a developer-preview beta, not a compatibility guarantee for every
  GM Host ABI 1.0 device or firmware build.
- Play requires GMPluginWindows and a Bluetooth SPP connection. USB-UART can
  install the package but does not provide the beta control and sound path.
- The beta contains one fixed matchup and one stage. There is no character
  selection, story mode, throw, aerial attack, save data, or online play.
- Sound is produced by the Windows companion tool, not by the glasses.
- Plugins currently run from RAM and must be reinstalled after a glasses reboot.
- Display residue must be assessed on real hardware; host builds cannot prove
  optical behavior.
