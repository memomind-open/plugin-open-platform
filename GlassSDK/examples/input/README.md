# Button input

Displays the latest stable plugin button/action value on the glass screen.
Single-click, double-click, and long-press events each show a distinct status
message and are also written to the Host log.

Use the Desktop Studio primary-button control to click once, click twice, or hold for one
second. The event remains visible until the next supported button event.

After changing this example, run `./gm-build` from the SDK root.
