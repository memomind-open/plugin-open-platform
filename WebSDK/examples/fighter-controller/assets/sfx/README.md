# Fighter Controller audio assets

The combat, match-flow, and music WAV files in this directory are original,
programmatically synthesized assets generated by
`WebSDK/tools/generate-fighter-audio.mjs`. They use only code-defined
oscillators, envelopes, deterministic noise, and original note sequences; no
recorded or third-party samples are included.

Regenerate the assets from the `WebSDK` directory:

```sh
node tools/generate-fighter-audio.mjs
```

The older input-confirmation WAV files are also original synthesized assets
copied from the former GMPluginWindows companion implementation.
