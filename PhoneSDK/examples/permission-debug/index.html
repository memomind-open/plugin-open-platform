01 · 我的便签 storage

用 Bridge 保存内容，再读取验证。不会使用 localStorage 偷渡。

02 · 文件书架 files.user-selected

由宿主选择文件，使用授权文件流读取。文本 / 图片 / 音频最多预览 1 MiB，不上传。

03 · 眼镜画板 display

小图仅是待发送预览；发送是否成功以下方宿主结果及眼镜显示为准。Desktop 配对请选择 GM Web Bridge。

06 · 眼镜录音 audio.capture

真机由眼镜麦克风采集；桌面模拟器会申请电脑麦克风权限，并把同样的 16 kHz 单声道 Opus 数据交给 H5。

07 · H5 音频播放器 audio.playback

所有声音都由当前 H5 页面播放；眼镜录音会先传给 H5，再封装为 Ogg Opus 播放。

08 · HTTP 请求 network

纯 H5 fetch，不经过 App 代理，不在插件内假装拒绝。默认 httpbin.org/get 支持 CORS；百度等普通网页可能禁止跨域读取。仅点击后请求输入地址；不附带 Cookie，不发送文件或位置。
